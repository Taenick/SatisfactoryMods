# SatisfactoryMods

Personal fork/rebuild of Satisfactory mods, kept here so fixes survive even if an
upstream author updates (or doesn't update) their version.

## Mods

- **[WPPRedux](WPPRedux/)** — Rebuild of Water Pools Plus Redux, restoring
  compatibility after a major engine update broke the original release. Lets
  you place a Water Extractor on a portable, paintable Water Pool instead of
  requiring natural deep water. Fixes a looping logo texture, Modular pool
  placement/collision/dismantle crashes, Water Extractor snap height, and
  both Rubber Ducky variants being unobtainable/invisible.

See each mod's own README for full details, fixes, and usage instructions.
